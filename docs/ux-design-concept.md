## User Flows

### Flow 1 — Мониторинг агентов
```
Открытие дашборда
  → Видит сцену с агентами (top-down grid)
  → Читает статусы агентов по цвету/иконке
  → Кликает на агента
  → Открывается Agent Panel (справа или Bottom Sheet на мобиле)
  → Читает детали: роль, статус, KPI, активность
  → Закрывает панель
```

### Flow 2 — Смена темы
```
Видит кнопку переключения темы в Header
  → Нажимает
  → Тема переключается (light ↔ dark)
  → Все цвета адаптируются через CSS-переменные
  → Настройка сохраняется в localStorage
```

### Flow 3 — Навигация по зонам (Sidebar)
```
Открывает Sidebar
  → Видит список зон офиса (zones)
  → Кликает на зону
  → Сцена центрируется на выбранной зоне
  → Выделенная зона подсвечивается
```

### Flow 4 — Мобильный пользователь
```
Открывает на устройстве <1024px
  → Видит Scene на всю ширину
  → Sidebar скрыт
  → Кликает на агента
  → Снизу появляется Bottom Sheet с деталями агента
  → Свайп вниз — закрывает панель
```

## UX-проблемы и решения

| # | Проблема | Решение |
|---|----------|---------|
| 1 | Изометрический вид сложен для восприятия — сложно понять позиции агентов | Переход на top-down (orthogonal) view — пиксель в пиксель, сетка читаема |
| 2 | Хардкодные цвета ломают тёмную тему | Все цвета через CSS-переменные (`--text`, `--bg`, `--accent`) |
| 3 | На мобиле Agent Panel перекрывает сцену | Bottom Sheet (<1024px) вместо боковой панели |
| 4 | Нет визуальной иерархии между зонами | Цветовое кодирование зон (bg-цвет + рамка в токене зоны) |
| 5 | Агенты не различимы — все одинаковые | Уникальный эмодзи + цвет статуса + имя под аватаром |

## Дизайн-токены

### Цвета (тёмная тема по умолчанию)

```css
/* Фоны */
--bg:              #1a1a2e;   /* основной фон страницы */
--panel-bg:        #16213e;   /* фон панелей и сайдбара */
--metrics-card-bg: #0f3460;   /* фон карточек KPI */

/* Текст */
--text:            #eaeaea;   /* основной текст */
--text-secondary:  #a0a0b0;   /* вторичный текст (роли, подписи) */
--text-muted:      #6e6e8a;   /* третичный текст (метки, временны́е метки) */

/* Акцент */
--accent:          #e94560;   /* акцентный цвет (кнопки, выделения) */
--accent-hover:    #ff6b81;   /* hover-состояние акцента */

/* Границы */
--border:          #2a2a4a;   /* границы компонентов */
--border-light:    #3a3a5a;   /* более светлые границы (hover) */
```

### Цвета (светлая тема)

```css
--bg:              #f5f5f7;
```

## Схемы лейаутов

### Desktop (≥1024px) — 3-колоночный

```

│                     HEADER (60px)                   │
├──────────┬──────────────────────────┬───────────────┤
│          │                          │               │
│ SIDEBAR  │      SCENE CENTER        │  AGENT PANEL  │
│  220px   │    (flex: 1, min 0)      │    320px      │
│          │                          │               │
│  • Зоны  │   top-down canvas grid   │  • Имя/роль  │
│  • Фильт │   агенты = круги+emoji   │  • KPI cards  │
│  • Стат  │   клик → выбор агента    │  • Heatmap    │
│          │                          │  • Timeline   │
│          │                          │  • Activity   │
├──────────┴──────────────────────────┴───────────────┤
│              BOTTOM BAR / METRICS (48px)            │
└─────────────────────────────────────────────────────┘
```

### Mobile (<1024px) — одноколоночный + Bottom Sheet


## Спецификации компонентов

### 1. Header

- Высота: 60px (desktop), 56px (mobile)
- Содержимое: логотип/название слева, ThemeToggle справа
- Фон: `var(--panel-bg)`, нижняя граница `1px solid var(--border)`
- Позиция: sticky top

### 2. Sidebar

- Ширина: 220px (фиксированная)
- Видимость: только ≥1024px
- Содержимое:
  - Список зон с цветовыми индикаторами
  - Фильтр по статусу агентов
  - Общая статистика (online / idle / sleeping)
- Фон: `var(--panel-bg)`
- Правая граница: `1px solid var(--border)`

### 3. Scene Grid (Canvas)

- Тип рендеринга: Canvas 2D, top-down orthogonal
- Размер тайла: 80×80px
- Агенты: круг диаметром 48px, цвет по статусу, эмодзи в центре, имя снизу
- Зоны: прямоугольники с полупрозрачной заливкой и рамкой в цвете зоны
- Клик: определяет ближайшего агента (hitTest по радиусу), вызывает `onAgentClick`
- Зум: колёсико мыши, кнопки ±, пинч (мобиль)

### 4. Agent Panel

- Ширина: 320px (desktop, справа)
- Режим: Bottom Sheet на <1024px (высота 70vh, slide-up анимация)
- Структура сверху вниз:
  1. Аватар + имя + роль + кнопка закрытия
  2. Текущий статус (цветной блок с иконкой)
  3. Текущая задача (если есть)
  4. KPI cards (2 колонки)
  5. Heatmap активности за день
  6. Временна́я шкала (0:00–24:00)
  7. Лента последних действий
  8. Кнопки быстрых действий

### 5. Bottom Bar

- Высота: 48px
- Только desktop
- Содержимое: сводные метрики (всего агентов, онлайн, задач, сообщений)
- Фон: `var(--panel-bg)`, верхняя граница `1px solid var(--border)`

### 6. Activity Feed

- Отдельная панель или вкладка (по ситуации)
- Элемент ленты: время + имя агента + текст действия
- Авто-скролл к последнему событию
- Максимум 50 видимых строк, старые скрываются

## Критерии приёмки

### Dev-чеклист

- [ ] `--bg`, `--panel-bg`, `--metrics-card-bg` применены ко всем фоновым элементам
- [ ] `--text`, `--text-secondary`, `--text-muted` — ни одного хардкодного цвета текста
- [ ] `--accent`, `--accent-hover` используются для кнопок и интерактивных элементов
- [ ] `--border`, `--border-light` — все рамки через переменные
- [ ] Переключение темы не требует перезагрузки — всё через CSS-переменные
- [ ] Sidebar виден только на ≥1024px
- [ ] Agent Panel → Bottom Sheet на <1024px
- [ ] Клик по агенту на Canvas работает (hitTest по радиусу 24px)
- [ ] Canvas рендерит top-down вид (без изометрии)
- [ ] Зоны визуально различимы (цвет + рамка)

### QA-чеклист

- [ ] Тёмная тема: весь текст читается, контрастность ≥ 4.5:1
- [ ] Светлая тема: весь текст читается, контрастность ≥ 4.5:1
- [ ] Agent Panel открывается кликом по агенту на desktop
- [ ] Bottom Sheet появляется свайпом / кликом на мобиле
- [ ] Смена темы сохраняется после перезагрузки страницы
