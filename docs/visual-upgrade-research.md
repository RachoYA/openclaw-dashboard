### 1.2 Что отличает «красивую стратегию» от «квадратиков»

| Элемент | «Квадратики» ❌ | «Стратегия» ✅ |
|---------|---------------|---------------|
| **Пол** | Однотонная заливка | Текстурированный тайл (паркет, ковёр, плитка) с вариациями |
| **Стены** | Линия или ничего | 3D-стены с толщиной, тенями, окнами |
| **Мебель** | Цветной прямоугольник | Детализированный спрайт с тенями и highlights |
| **Персонажи** | Цветной силуэт | Спрайт с одеждой, причёской, анимацией idle/walk/work |
| **Освещение** | Нет | Мягкие тени от объектов, свет из окон, свечение мониторов |
| **Детали** | Пусто между объектами | Провода, бумаги на столе, стаканы, стикеры, растения |
| **Анимация** | Статично или дёрганно | Плавные 4-8 кадровые анимации, частицы (пар кофе, искры) |
| **Атмосфера** | Стерильно | Тёплая палитра, ambient sounds, погодные эффекты за окном |
| **Переходы** | Мгновенно | Ease-in/out, параллакс при скролле, smooth zoom |

## 2. Конкретный план апгрейда

### Фаза 1: Текстуры и стены (1-2 дня)

**Сейчас:** Плоские цветные зоны на Canvas  
**Цель:** Текстурированные полы + 3D-стены

```
СЕЙЧАС:                     ПОСЛЕ:
┌──────────────┐             ┌──────────────┐
│              │             │▓▓▓▓▓▓▓▓▓▓▓▓▓▓│ ← 3D стена с тенью
│  фиолетовый  │             │ ┊ ┊ ┊ ┊ ┊ ┊ │ ← паркетный пол
│  квадрат     │             │ ┊ ┊ ┊ ┊ ┊ ┊ │    с вариациями
│              │             │ ┊ ┊ ┊ ┊ ┊ ┊ │
└──────────────┘             └──────────────┘
```

**Что нужно:**
- Тайлсет полов: паркет (PM/Dev), плитка (DevOps), ковёр (Common), линолеум (QA)
- 3D-стены: вид сверху-сбоку, с тенью на пол
- Переходы между зонами: дверные проёмы, пороги

### Фаза 2: Мебель и детали (2-3 дня)

**Сейчас:** Примитивные прямоугольники  
**Цель:** Детализированные спрайты с тенями

**Что нужно для каждого объекта:**
1. Основной спрайт (top-down или iso view)
2. Тень (отдельный слой, multiply blend)
3. Highlight / свечение (для мониторов, серверов)
4. Вариации (разные цвета стульев, разные позы предметов)

**Критические объекты (must have):**
| Объект | Приоритет | Детали |
|--------|----------|--------|
| Стол с монитором | 🔴 | Монитор светится, на столе мелочи (кружка, мышь, клавиатура) |
| Серверная стойка | 🔴 | LED мигают, вентилятор анимирован, кабели |
| Kanban-доска | 🔴 | Цветные стикеры, видимые колонки |
| Стул/кресло | 🟡 | 2-3 варианта, поворачивается с персонажем |
| Кофемашина | 🟡 | Пар анимирован, кружка на подставке |
| Растение | 🟡 | Лёгкое покачивание листьев |
| Диван | 🟢 | Мягкий, с подушками |
| Книжная полка | 🟢 | Разноцветные корешки книг |

### Фаза 3: Персонажи (2-3 дня)

**Сейчас:** Простые фигурки на Canvas  
**Цель:** Детализированные анимированные персонажи

| Аксессуары | Наушники (dev), планшет (PM), лупа (QA), документы (analyst) |

**Персонажи с уникальным стилем:**

| Агент | Одежда | Аксессуар | Цвет-акцент |

### Фаза 4: Освещение и атмосфера (1-2 дня)

| Эффект | Как реализовать | Сложность |
|--------|----------------|-----------|
| **Тени от мебели** | Отдельный shadow layer, multiply blend mode | Низкая |
| **Свечение мониторов** | Additive blend, голубой/зелёный glow | Низкая |
| **Свет из окон** | Градиент overlay, лучи (volumetric light sprites) | Средняя |
| **Пар от кофе** | Particle system — 3-5 прозрачных кружков, float up | Низкая |
| **LED на серверах** | Мигающие точки (toggle visibility по таймеру) | Низкая |
| **Пыль в лучах света** | Мелкие частицы в зоне окна | Средняя |
| **День/ночь** | Тёплый overlay днём, синий ночью, авто по времени | Средняя |

### Фаза 5: Анимации и polish (2-3 дня)

| Анимация | Описание | FPS |
|---------|----------|-----|
| Персонаж idle | Лёгкое покачивание, моргание | 2-4 |
| Персонаж walk | 6-8 кадров, плавный шаг | 8 |
| Персонаж work | Руки на клавиатуре, голова поворачивается | 4 |
| Пузырь сообщения | Fade in → float → fade out | CSS transition |
| Задача летит | Карточка от PM к Dev — arc trajectory | 30fps tweening |
| Конфетти (PR merged) | Burst particles, gravity, fade | 30fps |
| Экран монитора | Мерцание текста, скролл кода | 2 |
| Дверь открывается | При проходе персонажа | 4 кадра |
| Кресло поворот | При посадке персонажа | 4 кадра |

## 4. Web Engines для рендеринга

### 4.1 Сравнение движков

| Движок | Тип | Размер | FPS | Isometric | Тайлы | Анимации | Сложность |
|--------|-----|--------|-----|-----------|-------|----------|-----------|
| **PixiJS 8** | 2D WebGL | 150KB | 60 | Plugin | ✅ | ✅ | Средняя |
| **Phaser 3** | 2D Game | 1MB | 60 | Встроено | ✅ | ✅ | Средняя |
| **Phaser 4** | 2D Game | 800KB | 60 | Встроено | ✅ | ✅ | Средняя |
| **Kaboom.js** | 2D Game | 200KB | 60 | Нет | ✅ | ✅ | Низкая |
| **Three.js** | 3D WebGL | 600KB | 60 | Камера | Нет | ✅ | Высокая |
| **Canvas 2D** | Native | 0KB | 30-60 | Manual | Manual | Manual | Высокая |
| **CSS + SVG** | DOM | 0KB | 30 | Transform | Нет | CSS | Низкая |

### 4.2 Рекомендация

**Для нашего случая: PixiJS 8 + @pixi/tilemap**

Почему:
- Уже используется Canvas — миграция на PixiJS минимальна
- WebGL рендеринг — 60fps даже с сотнями спрайтов
- @pixi/tilemap — оптимизированный рендеринг тайловых карт
- pixi-spine / pixi-animate — продвинутые анимации
- pixi-particles — частицы (пар, конфетти, искры)
- 150KB — лёгкий
- Огромная экосистема плагинов

**Альтернатива: Phaser 3** если нужна полноценная игровая логика (pathfinding, collision detection, scene management).

## 6. Tiled Map Editor — инструмент для карты

**URL:** https://www.mapeditor.org (бесплатный, open-source)

Используется во всех перечисленных играх. Позволяет:
- Рисовать карту из тайлов визуально (drag & drop)
- Несколько слоёв (пол, стены, мебель, декор)
- Экспорт в JSON → загрузка в PixiJS/Phaser
- Object layer для спавна персонажей

**Workflow:**
1. Импортировать LimeZu тайлсет в Tiled
2. Нарисовать офис (PM Board, Dev Corner, QA Lab, etc.)
3. Расставить мебель
4. Экспорт → public/assets/maps/office.json
5. Загрузить в PixiJS через @pixi/tilemap
