# Архитектурная оценка: Анимированный дашборд агентов OpenClaw (стиль Sims)

---

## 1. Концепция

Визуальный real-time дашборд, где каждый AI-агент представлен как персонаж (à la Sims):
- Аватар с анимацией (idle, working, talking, thinking, sleeping)
- Статус-бабл (что делает сейчас)
- Связи между агентами (кто кому пишет)
- Общая «комната» или «офис» — пространство взаимодействия

## 2. Технический стек — сравнение

| Технология | Плюсы | Минусы | Вердикт |
|-----------|-------|--------|---------|
| **CSS Animations** | Простота, поддержка везде | Не масштабируется для сложных сцен, нет физики | ❌ Слишком примитивно |
| **Canvas 2D** | Хорошая производительность, простой API | Нет DOM-интеграции, ручное управление всем | ⚠️ Возможно, но много ручной работы |
| **PixiJS** | GPU-ускорение, спрайты, анимации, отличная 2D-производительность | Нет 3D, отдельная экосистема | ✅ **Рекомендация** |
| **Three.js** | 3D, шейдеры, мощность | Overkill для 2D-дашборда, сложность | ❌ Избыточно |
| **Phaser** | Игровой движок, физика, анимации | Тяжёлый, заточен под игры | ⚠️ Возможно |
| **React + Framer Motion** | Интеграция с React, декларативные анимации | Проблемы с производительностью при >20 элементов | ⚠️ Для простого варианта |

### Рекомендация: **PixiJS + React обёртка**

**Почему:**
- GPU-ускоренный 2D рендеринг — плавные анимации даже с 20+ агентами
- Sprite sheets для персонажей (idle, walk, work, talk)
- Particle effects (мысли, сообщения летят между агентами)
- `@pixi/react` — интеграция с React для UI-панелей
- Используется в production: Sims-like игры, дашборды, визуализации

**Альтернатива (MVP):** React + Framer Motion + CSS — если нужно быстро показать прототип без сложной анимации.

## 3. Источники данных об агентах

### OpenClaw предоставляет:

**a) Через CLI / internal API:**
```
openclaw status → 6 агентов, сессии, heartbeat статус
```

**b) Sessions tool (доступен агентам):**
- `sessions_list` — список сессий с фильтрами, последние сообщения
- `sessions_history` — история сообщений сессии
- `subagents list` — дочерние агенты

**c) Presence система:**
- Lightweight real-time view подключённых клиентов
- Поля: instanceId, host, mode, lastInputSeconds, version

**d) Heartbeat:**
- Периодический пинг (настраивается per-agent)
- Показывает активность: `1h (pm), disabled (analyst)...`

### Архитектура данных для дашборда:

```
┌──────────────┐     WebSocket/SSE      ┌──────────────────┐
│  OpenClaw    │ ──────────────────────→ │  Dashboard        │
│  Gateway     │                        │  (Browser)        │
│              │  Agent states:          │                   │
│  - sessions  │  - name, role           │  PixiJS canvas:   │
│  - presence  │  - status (active/idle) │  - Agent sprites  │
│  - heartbeat │  - current task         │  - Animations     │
│  - messages  │  - last message         │  - Connections    │
│              │  - inter-agent comms    │  - Status bubbles │
└──────────────┘                        └──────────────────┘
```

### Способ получения данных:

**Вариант A (рекомендуемый): Backend-for-Frontend (BFF)**
- Лёгкий Node.js/Python сервис, подключённый к OpenClaw Gateway
- Агрегирует данные из sessions, presence, heartbeat
- Отдаёт по WebSocket клиенту
- Polling Gateway каждые 5-10 сек

**Вариант B (простой): Direct polling**
- Фронтенд через REST API опрашивает бэкенд
- Бэкенд вызывает `openclaw` CLI
- Обновление каждые 10-30 сек
- Проще, но менее real-time

**Вариант C (продвинутый): Gateway WebSocket напрямую**
- Подключение к Gateway WS (`ws://127.0.0.1:18789`)
- Получение events в реальном времени
- Требует авторизацию и понимание протокола

## 5. Анимации персонажей

| Состояние | Анимация | Триггер |
|-----------|----------|---------|
| **Idle** | Лёгкое покачивание, моргание | Нет активности >30 сек |
| **Working** | Печатает на клавиатуре, документы летают | Агент обрабатывает задачу |
| **Talking** | Бабл с текстом, жесты | sessions_send между агентами |
| **Thinking** | Лампочка/шестерёнки над головой | Запрос к LLM |
| **Sleeping** | Z-z-z, закрытые глаза | Heartbeat disabled / ночь |
| **Celebrating** | Конфетти, прыжок | PR замёржен / задача закрыта |

## 6. Оценка сложности и сроков

### MVP (демонстрация концепта) — 1-2 недели
- Статичная сцена с аватарами агентов
- Статусы из `openclaw status` (polling каждые 30 сек)
- CSS анимации (простые: pulse, fade)
- React + Framer Motion
- Без спрайтов — иконки/эмодзи

### v1.0 (полноценный дашборд) — 4-6 недель
- PixiJS сцена с анимированными спрайтами
- Real-time данные через WebSocket (BFF)
- 6 типов анимаций
- Связи между агентами (кто кому пишет)
- Sidebar с деталями и историей
- Responsive

### v2.0 (wow-эффект) — 8-10 недель
- Кастомные спрайты (pixel art или vector)
- Физика (агенты двигаются по комнате)
- Timeline прошлых событий
- Sound effects (опционально)
- Настраиваемые сцены (офис, парк, космос)
