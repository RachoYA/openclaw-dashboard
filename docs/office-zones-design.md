Виртуальный офис делится на **5 тематических зон**, каждая отражает роль агента. Стиль: isometric pixel art (32×32 base tile).

```
│                                                                  │
│  ┌─────────────────┐  ┌──────────────┐  ┌─────────────────────┐ │
```

## 1. PM Board — Комната Project Manager

### Описание
Командный центр с Kanban-доской и календарём. Артём здесь распределяет задачи и координирует команду.

### Элементы интерьера

| Объект | Размер (tiles) | Интерактивность | Анимация |
|--------|---------------|-----------------|----------|
| **Kanban-доска** | 3×2 | Клик → показывает реальные задачи из GitHub | Карточки перемещаются между колонками |
| **Стол руководителя** | 2×1 | — | — |
| **Монитор** | 1×1 | Клик → activity feed | Мерцание экрана |
| **Календарь на стене** | 1×1 | Клик → дедлайны мероприятий | Подсветка текущего дня |
| **Кресло** | 1×1 | — | Вращается когда Артём думает |
| **Стопка документов** | 1×1 | — | Растёт при накоплении задач |
| **Телефон** | 0.5×0.5 | — | Звонит при входящем сообщении |

### Kanban-доска (живые данные)

```
┌─────────────────────────────────────┐
│           KANBAN BOARD              │
│                                     │
│  TODO    │ IN PROG │ REVIEW │ DONE  │
│  ┌────┐  │ ┌────┐  │ ┌────┐ │      │
│  │#71 │  │ │#66 │  │ │#78 │ │ ✅#37│
│  │#73 │  │ │#72 │  │        │ ✅#38│
│  │#74 │  │         │        │ ✅#41│
│  └────┘  │ └────┘  │ └────┘ │      │
└─────────────────────────────────────┘
```

### Анимации Артёма в этой зоне

| Действие | Анимация | Триггер |
|---------|----------|---------|
| Распределяет задачи | Стоит у Kanban, перемещает карточки | `sessions_send` с задачей |
| Проверяет статус | Сидит за столом, смотрит в монитор | `sessions_list` / status check |
| Общается | Поворачивается к двери, пузырь сообщения | Сообщение в группу |
| Думает | Сидит, рука у подбородка, вопросительный знак | Пауза между действиями |
| Доволен | Встаёт, показывает 👍 | Задача закрыта |

## 2. Dev Corner — Уголок разработчиков

### Описание
Два рабочих места с мониторами, серверная стойка на фоне. Коля и Макс сидят рядом, иногда обсуждают код.

### Элементы интерьера

| Объект | Размер | Интерактивность | Анимация |
|--------|--------|-----------------|----------|
| **Стол Коли** | 2×1 | Клик → текущий PR/задача | — |
| **Стол Макса** | 2×1 | Клик → текущий PR/задача | — |
| **Монитор ×4** | 1×1 каждый | Показывает реальный код (стилизованный) | Текст бежит по экрану при кодинге |
| **Серверная стойка** | 1×2 | Клик → статус сервисов | LED мигают (зелёные = ok, красные = error) |
| **Наушники** | 0.5×0.5 | — | На голове при deep work |
| **Доска со схемой** | 2×1 | Клик → архитектура | — |
| **Кружка с кофе** | 0.5×0.5 | — | Пар поднимается |
| **Стикеры на мониторе** | — | — | Появляются при новых TODO |
| **Резиновая уточка** | 0.5×0.5 | Easter egg: клик → quack | Покачивается |

### Мониторы (живые данные)

```
┌──────────┐ ┌──────────┐
│ > git pu │ │ def gene │
│ > npm te │ │   plan = │
│ ✅ 34/34 │ │   return │
│ > _      │ │   event_ │
└──────────┘ └──────────┘
  Коля         Макс
```

- При `git push` — мелькает diff (зелёный/красный)
- При `npm test` — бегут строки с ✅/❌
- При ошибке — экран красный, текст "SEGFAULT" (шутка)

### Анимации Dev в зоне

| Действие | Анимация | Триггер |
|---------|----------|---------|
| Кодит | Пальцы по клавиатуре, текст бежит на мониторе | File edit / git activity |
| Пушит код | Встаёт, жест «готово», на экране `git push` | Git push event |
| Дебажит | Хмурится, лупа к монитору, красные строки | Error в логах |
| Code review | Два монитора, переключается между ними | PR review |
| Обсуждает с Максом | Поворачиваются друг к другу, пузыри | Коммуникация Dev↔Dev |
| Получил задачу | Восклицательный знак, кивает, садится кодить | Входящая задача |
| CI passed | Зелёная галочка на экране, мини-фейерверк | CI success |
| CI failed | Красный X, хватается за голову | CI fail |

## 3. QA Lab — Лаборатория тестирования

### Описание
Лаборатория с тестовыми экранами, стендом для багов и чеклистами. Саша здесь прогоняет тесты и находит баги.

### Элементы интерьера

| Объект | Размер | Интерактивность | Анимация |
|--------|--------|-----------------|----------|
| **Тестовый стенд** (3 экрана) | 3×1 | Клик → результаты тестов | Экраны показывают ✅/❌ |
| **Bug Board** | 2×2 | Клик → открытые issues | Стикеры появляются при новых багах |
| **Лупа (на стене)** | 1×1 | — | Светится при активном тестировании |
| **Стол** | 2×1 | — | — |
| **Чеклист (бумажный)** | 1×1 | Клик → smoke test results | Галочки ставятся в реальном времени |
| **Микроскоп** | 1×1 | Easter egg | При клике — увеличивает случайный баг |
| **Банка с жуками** | 1×1 | Easter egg | Жуки = bugs, наполняется при issue create |

### Тестовый стенд (живые данные)

```
┌──────────┐ ┌──────────┐ ┌──────────┐
│ SMOKE    │ │ FUNC     │ │ E2E      │
│ ✅✅✅✅ │ │ ✅✅✅❌ │ │ ✅✅✅✅ │
│ ✅✅✅✅ │ │ ✅✅❌❌ │ │ ✅❌✅✅ │
│ 8/8 PASS │ │ 31/36    │ │ 34/36    │
└──────────┘ └──────────┘ └──────────┘
```

### Bug Board

```
┌────────────────────────────┐
│       🐛 BUG BOARD         │
│                            │
│  🔴 #71  🔴 #73           │
│  🟡 #66  🟡 #72           │
│  🟢 #37✓ 🟢 #38✓ 🟢 #41✓ │
│                            │
│  Open: 4  Closed: 12      │
└────────────────────────────┘
```

### Анимации Саши в зоне

| Действие | Анимация | Триггер |
|---------|----------|---------|
| Прогоняет тесты | Стоит у стенда, экраны мигают, галочки появляются | Test execution |
| Нашёл баг | Восклицательный знак! Бежит к Bug Board, лепит стикер | Issue created |
| Smoke test passed | Все экраны зелёные, Саша показывает 👍 | Smoke 8/8 |
| Test failed | Один экран красный, Саша хмурится, пишет отчёт | Test failure |
| Пишет сценарий | За столом, ручка + бумага | Creating test plan |
| Ретест | Снимает стикер с Bug Board, идёт к стенду | Re-test after fix |

## 7. Коридор и переходы

### Движение между зонами

Агенты перемещаются между зонами по коридору с анимацией ходьбы:

```
PM Board ←→ Corridor ←→ Dev Corner
                ↕
Analyst  ←→ Common  ←→ QA Lab
                ↕
           DevOps Room
```

| Переход | Когда |
|---------|------|
| PM → Dev | PM назначает задачу → идёт к Dev, отдаёт карточку |
| Dev → QA | Dev завершил → идёт к QA, передаёт на тестирование |
| QA → Dev | Нашёл баг → идёт к Dev с красным стикером |
| Anyone → Common | Idle → идёт пить кофе |
| Anyone → PM | Отчёт → идёт к PM с документом |
| DevOps → All | Deploy → обходит всех, объявляет |

### Анимация перемещения
- Персонаж встаёт со своего места
- Идёт по коридору (4-8 кадров ходьбы)
- Заходит в целевую зону
- Выполняет действие (передаёт документ, обсуждает)
- Возвращается на своё место

## 8. Технические спецификации спрайтов

### Tilemap офиса

| Параметр | Значение |
|----------|----------|
| Tile size | 32×32px (isometric: 64×32) |
| Office grid | 20×12 tiles (640×384 base) |
| Rendered size | 1280×768 (2× scale) |
| Layers | Floor → Furniture → Characters → Effects → UI |
| Format | PNG spritesheet + JSON atlas |

### Spritesheet персонажей

| Параметр | Значение |
|----------|----------|
| Character size | 32×48px (isometric) |
| Directions | 4 (N, S, E, W) или 8 |
| Animations per character | 10 действий × 4-8 кадров |
| Total frames per character | ~60-80 |
| Total characters | 6 (+ 2 резерв) |
| Spritesheet size | ~512×512px per character |

### Furniture sprites

| Категория | Количество | Формат |
|-----------|-----------|--------|
| Столы | 5 вариантов | 64×48px iso |
| Мониторы | 3 варианта (с анимацией экрана) | 32×48px |
| Стулья/кресла | 4 варианта | 32×32px |
| Стойки серверные | 2 варианта (с LED анимацией) | 32×64px |
| Доски | 3 варианта (Kanban, bug, research) | 64×64px |
| Декор | 10+ предметов | 16-32px |
